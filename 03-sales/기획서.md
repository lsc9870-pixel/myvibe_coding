# CSV 매출 자료 엑셀 입력 프로그램 기획서

## 목적

`csv` 폴더 바로 아래의 CSV 파일을 검사한 뒤, 내용을 `매출.xlsx`의 `매출` 시트에 모읍니다. 검사 중 문제가 발견되면 엑셀 파일과 CSV 파일을 변경하지 않습니다. 이 문서는 기획서이며, 실제 프로그램은 아직 작성하지 않습니다.

## 파일 구조

```text
03-sales/
├─ 기획서.md
├─ 매출.xlsx
├─ csv/                  # 처리할 CSV 파일
│  ├─ 예시1.csv
│  └─ 예시2.csv
├─ completed/            # 처리가 끝난 CSV 파일
└─ 프로그램 파일          # 추후 작성할 파이썬 파일
```

`csv` 바로 아래의 CSV 파일만 읽고, 그 안의 다른 폴더는 살펴보지 않습니다. `completed`가 없으면 필요한 시점에 만듭니다.

## 처리 순서

1. 프로그램이 있는 `03-sales` 폴더를 기준으로 `csv`, `completed`, `매출.xlsx`의 위치를 찾습니다.
2. `csv` 바로 아래의 CSV 파일을 찾고 파일 이름 오름차순으로 정렬합니다. 파일이 하나도 없으면 알리고 중단합니다.
3. 엑셀 파일과 `매출` 시트를 열 수 있는지 확인합니다. 시트의 1행을 제목으로 읽습니다.
4. 모든 CSV를 먼저 읽고 검사합니다. UTF-8(BOM이 있는 경우 포함)을 먼저 시도하고, 읽을 수 없으면 CP949를 시도합니다. 두 방식 모두 읽을 수 없으면 오류로 처리합니다. 각 CSV의 첫 행 제목과 열 순서가 엑셀 1행과 정확히 일치해야 합니다. 각 데이터 행의 열 개수도 제목의 열 개수와 같아야 합니다.
5. `completed`에 옮길 CSV와 같은 이름의 파일이 하나라도 있는지 확인합니다. 있으면 덮어쓰지 않고 중단합니다. 파일이나 폴더를 읽거나 쓸 수 없는 경우도 알리고 중단합니다.
6. 검사에 통과한 CSV 데이터는 파일 이름 순서대로, 각 파일 안에서는 원래 행 순서대로 이어 붙입니다. 모든 CSV가 제목만 있고 데이터 행이 없다면 기존 데이터만 비웁니다.
7. 변경 전 엑셀 파일을 되돌릴 수 있도록 임시 사본을 준비합니다. `매출` 시트의 2행부터 마지막 데이터 행까지 기존 셀의 값만 지우고, 준비한 데이터를 2행부터 씁니다. 1행과 다른 시트, 기존 셀 서식은 유지합니다. 새로 필요한 행은 기본 서식을 사용합니다.
8. 엑셀을 임시 파일로 저장하고 저장 결과를 확인한 다음 `매출.xlsx`에 반영합니다. 엑셀 저장이 정상적으로 끝난 뒤에만 CSV를 `completed`로 옮깁니다. 필요한 경우 이때 `completed`를 만듭니다.
9. 모든 파일을 옮기면 처리 결과를 알리고 임시 사본을 정리합니다. 이동 중 오류가 나면 이동을 멈추고 이미 옮긴 CSV와 엑셀을 원래 상태로 되돌립니다. 되돌리기에도 오류가 나면 어떤 파일이 복구되지 않았는지와 임시 사본의 위치를 알립니다.

## 값의 처리 기준

- 제목은 글자와 순서를 정확히 비교합니다. 자동으로 고치거나 순서를 바꾸지 않습니다.
- 정수, 소수, 음수 형태의 값은 숫자로 입력합니다. `00123`처럼 앞에 0이 붙은 값은 앞의 0이 유지되도록 문자로 입력합니다.
- `YYYY-MM-DD` 형태이고 실제로 존재하는 날짜는 날짜로 입력합니다. 같은 형태라도 실제로 존재하지 않는 날짜는 원래 문자 그대로 입력합니다. 다른 형태의 날짜도 문자로 입력합니다.
- 위 기준에 해당하지 않는 값은 문자 그대로 입력합니다. 예를 들어 쉼표가 들어간 숫자는 자동으로 숫자로 바꾸지 않습니다.

## 오류 처리

- 엑셀 파일이나 `매출` 시트가 없거나 열 수 없으면 원인을 알리고 중단합니다.
- CSV가 없거나, CSV를 읽을 수 없거나, 제목 또는 데이터 행의 열 개수가 맞지 않으면 문제가 있는 파일과 내용을 알리고 중단합니다.
- `completed`에 같은 이름의 파일이 있으면 해당 이름을 알리고 중단합니다.
- 모든 CSV 검사와 이름 충돌 확인을 마치기 전에는 엑셀과 CSV를 변경하지 않습니다.
- 엑셀 저장에 실패하면 CSV를 옮기지 않고 엑셀을 원래 상태로 되돌립니다. CSV 이동 도중 실패했을 때도 위 복구 절차를 따릅니다. 저장 또는 복구에 실패한 이유를 사용자에게 알립니다.

## 실행 방법

추후 파이썬으로 프로그램을 작성한 다음, 파이썬과 `openpyxl`이 준비된 환경에서 실행합니다. `매출.xlsx`와 `csv` 폴더를 위 구조에 맞게 두고, CSV 파일을 `csv` 폴더에 넣습니다. 프로그램 파일 이름과 구체적인 실행 명령은 실제 프로그램을 작성할 때 정합니다.

## 완료 기준

- [ ] `csv` 바로 아래의 모든 CSV를 파일 이름 오름차순으로 읽습니다.
- [ ] 모든 파일의 제목, 열 순서와 데이터 행의 열 개수를 확인하고, 오류가 있으면 엑셀과 CSV를 변경하지 않습니다.
- [ ] CSV가 없으면 중단하고, 모든 CSV에 데이터 행이 없으면 기존 데이터 값을 비웁니다.
- [ ] 숫자, 앞에 0이 붙은 값, 날짜와 잘못된 날짜를 위 기준대로 처리합니다.
- [ ] 기존 데이터 값을 지운 뒤 새 데이터를 2행부터 입력하고, 1행과 다른 시트 및 기존 셀 서식을 유지합니다. 추가 행은 기본 서식을 사용합니다.
- [ ] `completed`의 같은 이름 파일을 덮어쓰지 않고, 충돌 시 작업을 중단합니다.
- [ ] 엑셀이 정상적으로 저장된 뒤 CSV를 이동하고, 필요한 경우 `completed`를 만듭니다.
- [ ] 이동 중 오류가 나면 엑셀과 이동한 CSV를 되돌리고, 복구 실패 시 그 사실과 복구에 필요한 정보를 알립니다.
- [ ] 파이썬과 `openpyxl`을 사용하며, 실행 결과 또는 오류를 이해하기 쉽게 알립니다.
