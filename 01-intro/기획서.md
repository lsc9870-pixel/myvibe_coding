# 자기소개 웹페이지 기획서

## 1. 프로젝트 소개
- **프로젝트 이름:** 모카의 자기소개
- **만드는 목적:** 수업에서 처음 만난 친구들에게 가상의 인물 모카를 쉽고 친근하게 소개합니다.
- **보는 사람:** 수업에서 만난 친구들

## 2. 소개할 인물
- **별명:** 모카
- **나이:** 37세
- **이전 경력:** SK네트웍스에서 11년간 근무한 뒤 희망퇴직
- **현재:** 새로운 진로를 고민하며 코딩을 배우는 중
- **성격:** 처음에는 조용하지만 친해지면 농담을 좋아함
- **사는 곳:** 가상의 도시 구름시
- **취미:** 카페 탐방, 산책과 사진 찍기, 요리, 음악 감상
- **좋아하는 음식:** 파스타와 따뜻한 국물 요리
- **관심사:** 주식 투자
- **목표:** 자기소개 웹페이지를 완성하고 일상에 도움이 되는 프로그램 만들기
- **친구들에게 한마디:** 커피나 산책을 좋아한다면 편하게 말을 걸어주세요!

## 3. 페이지에 넣을 내용
- [ ] 첫인사와 별명
- [ ] 간단한 자기소개와 이전 경력
- [ ] 취미와 좋아하는 것
- [ ] 코딩을 배우는 이유와 앞으로의 목표
- [ ] 수업 친구들에게 전하는 말
- [ ] 주식 투자에 대한 관심

## 4. 화면 구성
1. **첫 화면:** 별명과 짧은 인사
2. **나를 소개해요:** 성격, 경력과 현재의 관심사
3. **좋아하는 것:** 취미와 음식
4. **앞으로의 목표:** 코딩을 배우는 이유와 목표
5. **마지막 인사:** 친구들에게 전하는 말

## 5. 디자인 정하기
- **전체 분위기:** 가을의 따뜻하고 친근한 느낌
- **주요 색상:** 단풍의 빨간색과 주황색, 은행잎의 노란색
- **글자와 배경:** 읽기 쉽도록 정하기
- **배경 그림:** 가을 남산을 배경으로 단풍나무와 은행나무가 보이는 풍경
- **참고할 디자인:** 과하거나 어지럽지 않은 차분한 구성
- **움직임 분위기:** 애니메이션처럼 따뜻한 느낌

## 6. 기능 정하기
- [ ] 컴퓨터와 휴대전화 화면에서 읽기 편하게 보이기
- [ ] 각 소개 영역으로 이동하는 메뉴
- [ ] 낙엽이 떨어지는 효과

## 7. 만들 파일
- `index.html`: 웹페이지의 내용과 구조
- `style.css`: 색상과 화면 꾸미기
- 낙엽 효과에 필요한 추가 파일은 제작할 때 정합니다.

## 8. 작업 순서
1. 기획서의 빈칸과 필요한 기능을 정합니다.
2. 자기소개 내용을 작성합니다.
3. 웹페이지의 내용과 화면을 만듭니다.
4. 컴퓨터와 휴대전화 크기에서 화면을 확인합니다.
5. 오타와 기능을 확인하고 필요한 부분을 고칩니다.

## 9. 완료 기준
- [ ] 가상의 인물 모카의 인사, 경력, 취미, 목표가 보입니다.
- [ ] 수업 친구들에게 전하는 말이 보입니다.
- [ ] 컴퓨터와 휴대전화 크기에서 내용이 읽기 편합니다.
- [ ] 선택한 메뉴와 추가 기능이 제대로 작동합니다.
- [ ] 실제 개인 정보나 비밀 정보가 들어 있지 않습니다.
